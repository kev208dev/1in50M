# 선택·경제·삶별 분기 통합 검증

## 반영 범위

기준 커밋 e2e194a. 원격에 추가된 세 개 패치(장면·딜레마 엔진 및 콘텐츠)를 먼저 그대로 반영했다. sources/는 수정하지 않았다.

- 선택지의 이전/다음 제거. 모든 카드를 함께 표시하고, 선택한 카드의 상세를 읽은 뒤 확정한다. 잠긴 카드도 설명을 확인할 수 있지만 실행은 불가능하다.
- 가족 동거자의 개인 부담과 독립 가구 비용을 구분한다. 24세 이하 준비·재학 중 인물은 남은 가정 지원 범위 안에서만 도움받는다. 기존 마이너스 현금과 부채를 지우지 않는다.
- 바로 취업/중소기업 취업이 실제 지속 급여를 만든다. 자동 취업이 유급 훈련·자영업·은퇴를 덮어쓰지 않는다.
- 자산 배분은 현금의 최대 10% 이내, 최소 1만원부터. 현금 10만원 미만이면 투자 대신 자금 마련 또는 유보 경로가 있다. 예금·주식 등의 매수는 현금과 자산 간 이동이다.
- 진학은 학력 조건을 유지하되 학비를 가정 지원/개인 현금/학자금 빚으로 명시하여 비교한다. 실존 대출 상품이나 자격 보장이 아닌 게임용 단순화다.
- 8개 추가 경로: 소득 회복, 유급훈련 후속, 교대근무 후속, 대학 생활과 일, 돌봄 뒤 복귀, 접근 가능한 일터, 지역 생업, 자영업 운영. 이전 선택과 현재 상황에 따라 후보가 달라진다.
- 연간 소득/생활비/이자/가정 지원/현금 변화를 메시지에 기록한다. 집 선택의 초기 현금·월 주거비·주택 부채 표시를 수정했다.

## 실제 브라우저 검증

CUA의 로컬 검증 페이지는 실제 게임의 HTML/CSS/렌더러를 사용한다. 테스트 저장 데이터는 localhost에만 만들었고 사용자의 배포 사이트 저장 데이터는 변경하지 않았다.

- 1440×900: 투자 선택 6개 동시 표시, 예금 10만원 실행 후 현금 90만원/순자산 100만원 확인.
- 320×568: 고등학교 선택 8개 및 진학 선택 6개. 카드/폼/다이얼로그 크기 측정에서 잘림 없음. 진학 상세와 확정 버튼도 화면 안에 표시.
- 844×390: 가로 화면에서 진학 선택 6개와 상세/확정 버튼 표시, 잘림 없음.
- 실제 앱 이어하기 → 투자 → 복무 → 소득 회복 → 유급 훈련 → 다음 해 숙련직 선택까지 진행. 월 소득 180만원과 다음 해 270만원 반영 확인. 유급 훈련 연간 현금 +1,200만원 메시지 확인.
- 390×844: 실제 앱의 페이지 크기 390×844와 모바일 미디어쿼리 적용은 확인. 크기 변경 직후 스크린샷이 이전 프레임을 보여 재촬영을 시도했으나 접근이 꺼졌으므로, 이 뷰포트의 최종 시각 검증 완료는 주장하지 않는다.

증거: `artifacts/2026-10-19-opportunities/desktop-choices.jpg`.

브라우저 접근이 이후 Work 설정에서 비활성화되었다. 마지막 주거 비용/지역 조건 수정과 배포본은 추가 브라우저 검증이 아닌 자동 테스트 및 배포 파일 확인 대상이다.

## 자동 검증

- 최종 `npm test`: 313개 통과, 실패 0개. `git diff --check` 통과.
- 신규 회귀 테스트는 변경 전 실패를 확인한 뒤 통과시켰다: 생활비/실제 취업 소득/선택한 직업 유지/소액 투자 자산 보존/마이너스 현금 경로/학비 분담/후속 경로/주거 비용/이사 뒤 지역 조건.
- 장면 구조 검사: 12,773개 사건 조합, 2,459개 딜레마 변형 검사에서 문장 중복·조사/자리표시·길이 규칙 문제 없음. 조합 수는 독립적으로 집필한 이야기 수가 아니다.
- 최신 20개 생애 실행: 진행 멈춤 없음, 118개 장면 계열/1,379개 서로 다른 사건 문장 관찰. 검사 규칙상 맥락 위반 0, 반복 문장 0. 선택 가능 카드가 하나뿐인 결정 비율 1.5%, 실제 자동 중단은 연평균 0.492회. 설정된 9개 품질 기준 모두 통과.
- 기존 감사 도구는 알림을 감지할 때마다 강제 팝업으로 잘못 계산했다. 실제 앱의 `createEventNotice`를 사용하여 명시적 열기만 팝업으로 집계하도록 수정했다.

## 검토와 판단

- 별도 리뷰어가 주거 비용 누락과 이사 후 농촌 조건 문제를 확인했다. 사용량 제한으로 전체 최종 판정 전에 중단되어, 두 문제를 회귀 테스트로 고치고 나머지는 작성자가 직접 검토했다. 독립 검토가 완결됐다고 주장하지 않는다.
- 새 콘텐츠 엔진을 다시 만들지 않고 사용자가 추가한 확장 위에 후속 경로를 연결했다. 범위가 부족하면 추가 집필이 필요하며 ‘대한민국의 모든 삶’을 완전히 구현했다는 뜻은 아니다.
- 모든 카드를 보이게 하되 상세 비교 후 확정하는 방식을 선택했다. 작은 화면 가독성과 오선택 방지를 얻는 대신 확정 클릭 한 번이 추가된다.
- 학비 조달은 명시적인 단순화다. 현실보다 넓은 자금 접근성을 제공하는 대신 가정 지원 감소와 부채 부담을 실제 상태에 반영한다.
- 기존에 승인된 main/GitHub Pages 배포 흐름을 유지한다. 변경은 공개되지만 커밋 단위 되돌리기가 가능하다.
- 런타임 AI 호출/요금/비밀 키는 추가하지 않았다. 개발 단계에서 작성한 결정형 콘텐츠를 게임이 실행한다.
