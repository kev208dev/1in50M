# 5000만 분의 1 — 전체 생애 시뮬레이션 설계

## 목표와 선택한 방향

현재 구현된 랜덤 출생 경험을 출발점으로 삼아, 사용자가 대한민국에서 태어나 성장하고 교육·진로·직업·주거·관계·가족·노후를 선택하며 한 생애를 끝까지 살아보는 인터랙티브 시뮬레이션으로 확장한다.

사용자가 승인한 방향은 **원작형 자동 진행 방식**이다. 시간은 자동으로 흐르고, 중요한 사건이나 결정 앞에서 멈춘다. 사용자는 선택을 내린 뒤 다시 시간을 흐르게 하며, 선택과 초기 환경이 상태·돈·관계·인생 기록에 누적된다.

원작의 문구·그래픽·코드를 복제하지 않는다. 자동 시간 흐름, 선택에서의 일시정지, 상태 패널, 인생 기록, 생애 결과 같은 상호작용 구조와 정서를 참고하되 대한민국의 제도와 삶의 단계에 맞는 독자적인 콘텐츠와 화면을 만든다.

## 성공 기준

- 랜덤 출생부터 생애 종료까지 한 번의 삶을 완주할 수 있다.
- 1회 플레이는 기본 속도에서 약 12~18분, 배속 사용 시 5분 안에도 끝낼 수 있다.
- 교육, 취업, 주거, 관계, 건강의 핵심 결정을 사용자가 직접 내린다.
- 결정은 상태와 이후 선택지에 영향을 주지만 결과를 완전히 확정하지 않는다.
- 출생 조건이 다른 두 삶이 눈에 띄게 다른 기회와 사건 흐름을 만든다.
- 모바일 360px부터 데스크톱까지 같은 기능을 사용할 수 있다.
- 실제 데이터가 아닌 모든 수치는 체험용 가상 시뮬레이션임을 명확히 표시한다.

## 전체 사용자 흐름

1. 사용자는 출생 조건을 무작위로 뽑는다.
2. 마음에 들지 않으면 다시 뽑고, 마음에 들면 `이 인생 시작하기`를 누른다.
3. 출생 카드가 축소되어 생애 시뮬레이션 화면으로 전환된다.
4. 나이가 자동으로 증가하고 한 해의 주요 사건이 인생 기록에 쌓인다.
5. 교육, 진로, 일, 주거, 관계, 건강 결정이 나타나면 시간이 멈춘다.
6. 사용자는 선택하거나 `자동 결정`에 맡긴다.
7. 상태·자산·가족·직업·거주지가 해마다 변한다.
8. 생애 종료 시 인생 요약, 주요 결정, 상태 그래프, 자산 변화, 다시 살아보기 기능을 본다.
9. 완료한 삶은 브라우저에 최대 10개까지 전생 기록으로 남는다.

## 시간 엔진

### 진행 단위

- 내부 계산 단위는 1년이다.
- 기본 1배속에서 1년은 약 8초다.
- 속도는 `1×`, `2×`, `4×`, `8×`, `16×`를 제공한다.
- `일시정지`, `다음 결정까지`, `자동 결정`을 제공한다.
- 탭이 백그라운드에 있거나 화면이 잠기면 시간은 흐르지 않는다.
- 결정 창이 열리면 항상 자동으로 멈춘다.

### 나이 범위

- 0세부터 시작한다.
- 건강과 사건에 따라 생애 종료 시점이 달라진다.
- 90세에는 확률과 무관하게 마지막 회고 단계로 진입한다.
- 생애 종료는 폭력적이거나 자극적인 장면 없이 짧은 기록과 회고로 표현한다.

### 재현 가능한 난수

- 각 삶은 출생 시 생성한 `seed`를 가진다.
- 같은 저장 상태를 다시 열면 같은 시점까지 동일한 사건 순서가 유지된다.
- 사용자의 선택 이후 결과는 선택값과 seed를 함께 사용해 계산한다.
- 애니메이션용 난수와 시뮬레이션 난수를 분리해 화면 효과가 결과를 바꾸지 않게 한다.

## 상태 모델

### 핵심 상태 0~100

- `건강`: 질병·활동 가능성·수명에 영향을 준다.
- `행복`: 삶의 만족감과 스트레스 사건에 영향을 준다.
- `지식`: 진학·시험·직업 제안·초봉에 영향을 준다.
- `관계`: 가족·친구·연애·외로움 사건에 영향을 준다.

### 경제 상태

- 현금
- 월 소득
- 월 고정비
- 부채
- 주거 보증금 또는 주택 자산
- 순자산

금액은 체감하기 쉬운 원화로 보여 주되 실제 통계나 재무 조언으로 표현하지 않는다. 경제 수치는 연령대와 직업군에 맞는 체험용 범위에서 움직인다.

### 프로필 상태

- 나이와 연도
- 현재 거주지
- 학력과 재학 상태
- 학교 유형
- 직업군과 세부 직업
- 고용 상태
- 가족 구성
- 연애·혼인 상태
- 자녀 수
- 주거 형태
- 올해의 초점

## 생애 단계와 핵심 결정

### 0~6세: 유년기

- 가족과 주거 환경을 소개한다.
- 부모의 고용 변화, 돌봄, 이사, 건강 같은 짧은 사건이 발생한다.
- 사용자 결정은 최소화하고 초기 상태가 형성되는 과정을 보여 준다.
- 5세에 첫 회고 질문을 표시한다.

### 7~12세: 초등학교

- 학교 적응, 친구, 학습, 방과후 활동 사건이 발생한다.
- 선택: 공부, 운동, 예술, 친구, 휴식 중 올해의 초점.
- 가정 형편과 거주지는 선택 가능 범위에 영향을 주지만 특정 선택을 완전히 차단하지 않는다.

### 13~15세: 중학교

- 성적, 관계, 진로 관심, 스트레스 사건이 강화된다.
- 선택: 학업 집중, 자격·기술 탐색, 예체능 준비, 관계, 휴식.
- 15세에 고등학교 선택 결정이 열린다.

### 16~18세: 고등학교

사용자는 다음 유형에서 조건에 따라 지원하거나 진학한다.

- 일반고
- 특성화고
- 마이스터고
- 자율형 사립고
- 특수목적고
- 예술고
- 체육고
- 대안학교·검정고시 경로

각 학교는 학비 부담, 지식 증가, 기술 숙련, 스트레스, 취업·진학 선택지에 서로 다른 영향을 준다. 학교 유형은 성공 순위가 아니라 다른 경로로 표현한다.

### 19~24세: 진학·취업·복무

- 4년제 대학
- 전문대학
- 직업훈련·자격증
- 바로 취업
- 창업 준비
- 재도전·휴식

병역 관련 경로는 출생 프로필의 복무 대상 여부와 건강 조건에 따라 선택지로 나타난다. 성별 자체를 능력치나 성공 확률에 연결하지 않는다. 복무 경로는 현역, 대체·보충 복무, 면제·비대상으로 단순화하며 실제 법률 판정 도구처럼 표현하지 않는다.

### 25~39세: 직업·독립·관계

- 직업군과 세부 직업 선택
- 취업 제안 수락·거절
- 이직·자격 취득·창업·휴직
- 부모와 동거, 월세, 전세, 공공임대, 자가 선택
- 수도권·광역시·지역 간 이주
- 연애·결혼·비혼·자녀 선택

### 40~59세: 중년기

- 승진·직업 전환·실직·재취업
- 가족 돌봄과 자녀 교육
- 부채 상환과 주거 이동
- 정기검진·운동·휴식·과로 선택
- 50세에 중간 생애 회고 질문

### 60세 이후: 은퇴·노년기

- 계속 일하기, 은퇴, 시간제 일, 지역 활동
- 연금과 자산 사용
- 건강 관리와 관계 유지
- 자녀·친구·지역사회 사건
- 70세에 마지막 주요 회고 질문

## 직업 시스템

### 직업군

- 경영·사무
- 연구·전문
- 교육·공공
- 보건·복지
- 문화·예술·미디어
- 서비스·판매
- 생산·기술
- 건설·설비
- 운송·물류
- 농림어업
- IT·데이터
- 자영업·창업

### 직업 선택 구조

- 직업군을 먼저 고르고, 해당 군의 세부 직업 4~8개를 보여 준다.
- 학력·지식·기술·거주지에 따라 제안 확률과 초봉 범위가 달라진다.
- 요구 조건을 충족하지 못해도 준비하기, 다른 경로 찾기 같은 대체 선택을 제공한다.
- 직업은 안정성, 소득, 스트레스, 건강, 관계에 서로 다른 영향을 준다.
- 2~5년마다 승진·이직·고용 변화 가능성을 평가한다.

## 결정 시스템

각 결정은 다음 구조를 가진다.

- 제목과 현재 상황
- 2~4개의 선택지
- 선택 조건
- 즉시 효과
- 장기 효과 태그
- 비용 또는 필요 시간
- 선택 후 짧은 결과 문장

선택지의 숫자 효과를 미리 모두 공개하지 않는다. 대신 `건강에 도움`, `비용이 큼`, `지식이 필요`, `관계에 영향` 같은 방향성 태그를 표시한다.

조건을 충족하지 못한 선택지는 숨기지 않고 비활성 상태로 보여 주며, 필요한 조건을 설명한다. 선택지가 하나뿐이어도 자동으로 넘기지 않고 사용자가 상황을 읽을 수 있게 한다.

## 연간 사건 시스템

### 사건 범주

- 가족
- 학교·학업
- 친구·연애
- 직업·소득
- 주거·이사
- 건강
- 사회·생활
- 행운·예상 밖의 변화

### 사건 규칙

- 한 해에 0~2개의 사건이 발생한다.
- 같은 사건이 짧은 기간 안에 반복되지 않도록 쿨다운을 둔다.
- 나이, 현재 상태, 과거 선택, 지역, 가족, 직업을 조건으로 사용한다.
- 특정 지역·가족 형태·성별을 부정적인 사건과 직접 연결하지 않는다.
- 사건은 체험용 창작 데이터이며 실제 개인의 미래를 예측하지 않는다.

## 올해의 초점

사용자는 언제든 다음 중 하나를 선택한다.

- 공부·성장
- 건강 관리
- 사람과 관계
- 돈과 경력
- 휴식과 균형

초점은 매년 작은 보정치를 주며, 다른 선택이나 환경을 압도하지 않는다. 자동 결정 모드에서는 현재 가장 낮은 상태와 인생 단계에 따라 초점을 고른다.

## 화면 구성

### 데스크톱

상단 고정 바:

- 프로젝트명
- 현재 나이와 연도
- 일시정지
- 속도 선택
- 다음 결정까지
- 자동 결정
- 메뉴

본문 3영역:

1. 왼쪽: 프로필, 핵심 상태, 돈, 올해의 초점
2. 중앙: 현재 사건 또는 결정, 인생 기록, 나이 진행선
3. 오른쪽: 가족·관계, 학교·직업, 주거, 간단한 생존·자산 그래프

### 모바일

- 상단에는 나이, 재생·정지, 속도만 유지한다.
- 현재 사건과 결정을 화면 중심에 둔다.
- 상태·가족·돈은 접을 수 있는 하단 시트 또는 탭으로 제공한다.
- 결정이 나타나면 전체 화면 카드로 전환한다.
- 주요 선택 버튼은 화면 하단 안전 영역 위에 고정한다.

### 인생 지도

- 한 칸이 1년인 가로형 또는 감싸지는 격자를 제공한다.
- 학교, 취업, 이사, 결혼, 자녀, 은퇴 같은 전환점을 초록색으로 표시한다.
- 현재 나이는 밝은 점과 스캔 라인으로 강조한다.
- 기록 항목을 누르면 해당 나이의 사건을 다시 읽을 수 있다.

## 저장과 이어하기

- 현재 삶 전체를 `localStorage`에 저장한다.
- 저장은 매년 진행 후, 결정 후, 화면을 떠나기 전에 수행한다.
- 저장 버전 번호를 포함하고 잘못된 데이터는 안전하게 초기화한다.
- 이어하기 버튼은 유효한 미완료 삶이 있을 때만 보인다.
- 완료한 삶은 요약본만 최대 10개 저장한다.
- 사용자는 현재 삶이나 전생 기록을 개별 삭제하거나 전체 초기화할 수 있다.

## 생애 종료와 결과

결과 화면에는 다음을 표시한다.

- 출생지, 최종 거주지
- 학교와 주요 진로
- 가장 오래 한 직업
- 가족과 관계 요약
- 최종 순자산
- 건강·행복·지식·관계 변화 그래프
- 삶을 바꾼 결정 5개
- 한 문단 인생 요약
- `같은 조건으로 다시`, `완전히 다른 삶`, `전생 기록 보기`

삶에 점수나 성공·실패 등급을 매기지 않는다.

## 데이터와 윤리 원칙

- 이번 전체판도 실제 통계 API를 사용하지 않는다.
- 모든 확률과 금액은 체험용 가상 데이터다.
- 화면 상단 메뉴와 주요 결과 화면에 이를 반복해서 안내한다.
- 가난, 실업, 질병, 가족 형태를 개인의 잘못처럼 표현하지 않는다.
- 자살, 범죄, 성폭력, 구체적인 사망 방법처럼 고위험·자극적 사건은 이번 버전에서 다루지 않는다.
- 병역·입시·부동산 선택은 실제 법률, 합격, 재무 판단 도구가 아님을 명시한다.

## 기술 구조

정적 HTML·CSS·JavaScript 구조를 유지하되 파일을 역할별 ES 모듈로 분리한다.

- `dist/data/regions.js`: 지역과 세부 거주지
- `dist/data/life-events.js`: 연령·상태별 사건
- `dist/data/decisions.js`: 결정과 선택지
- `dist/data/education.js`: 학교·진학 경로
- `dist/data/careers.js`: 직업군·직업·소득 범위
- `dist/engine/random.js`: seed 기반 난수
- `dist/engine/life.js`: 연도 진행과 상태 변화
- `dist/engine/conditions.js`: 조건·선택지 판정
- `dist/engine/economy.js`: 소득·지출·자산 계산
- `dist/engine/history.js`: 인생 기록과 주요 사건
- `dist/storage.js`: 버전 저장·복구·전생 기록
- `dist/ui/render.js`: 상태와 패널 렌더링
- `dist/ui/controls.js`: 재생·속도·결정 입력
- `dist/app.js`: 화면 전환과 모듈 조립

각 엔진 함수는 DOM에 의존하지 않고 테스트 가능한 순수 함수로 만든다.

## 오류와 경계 상황

- 저장 데이터가 손상되면 안내 후 새 삶으로 복구한다.
- 선택 가능한 항목이 없으면 안전한 기본 선택지를 제공한다.
- 수치가 `NaN`이나 범위를 벗어나면 저장 전에 보정한다.
- 탭 복귀 시 누락된 시간을 한꺼번에 진행하지 않는다.
- 버튼 연타로 같은 연도가 두 번 처리되지 않게 진행 잠금을 둔다.
- 데이터에 없는 직업·학교 ID가 저장돼 있으면 일반 경로로 대체한다.

## 접근성

- 키보드만으로 재생, 속도, 결정, 메뉴를 조작할 수 있다.
- 결정이 열리면 포커스를 제목으로 이동하고 닫은 뒤 원래 위치로 돌린다.
- 상태 변화는 중요한 항목만 `aria-live`로 알린다.
- 그래프에는 같은 내용을 설명하는 텍스트 요약을 제공한다.
- `prefers-reduced-motion`에서는 스캔, 셔플, 숫자 전환 모션을 생략한다.
- 터치 영역은 최소 44px로 유지한다.
