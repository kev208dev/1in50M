# 5000만 분의 1 — 랜덤 출생 MVP 설계

## 목표

대한민국에서 태어나는 한 사람의 초기 조건을 무작위로 생성하고, 사용자가 마음에 드는 삶이 나올 때까지 반복해서 다시 뽑을 수 있는 모바일 중심 웹 경험을 만든다. 이번 MVP는 전체 인생 시뮬레이션을 복제하지 않고, `랜덤 출생 → 조건 확인 → 다시 태어나기 → 이 인생 시작하기` 흐름의 완성도에 집중한다.

## 핵심 사용자 흐름

1. 사용자는 인트로에서 `5000만 분의 1`과 짧은 설명을 본다.
2. `태어나기`를 누르면 대한민국 내 출생 조건이 생성된다.
3. 생성 과정은 짧은 셔플 애니메이션으로 보여 주되 반복 사용을 방해하지 않는다.
4. 결과 화면에서 출생 연도, 지역, 세부 거주지, 가족 구성, 부모 직업, 가정 형편과 초기 능력치를 확인한다.
5. 사용자는 `다시 태어나기`를 눌러 즉시 새 결과를 얻거나 `이전 인생`으로 직전 결과를 되돌린다.
6. `이 인생 시작하기`를 누르면 선택한 프로필이 확정되고, 다음 성장 단계에서 고등학교와 진로를 선택하게 된다는 예고 화면으로 이동한다.

## 화면 구조

### 1. 인트로

- 프로젝트명: `5000만 분의 1`
- 보조 문구: `대한민국 어딘가에서, 다시 태어납니다.`
- 데이터 안내: 실제 통계 연동 전 단계의 가상 시뮬레이션임을 첫 화면부터 명시
- 주요 동작: `태어나기`
- 배경에는 대한민국의 행정 구역을 연상시키는 추상적인 선과 작은 좌표 표시를 사용한다. 실제 지도를 정밀하게 묘사하지 않아도 된다.

### 2. 생성 중 상태

- 지역명과 가족 조건이 빠르게 교체되는 짧은 셔플 효과
- 0.8~1.2초 안에 종료해 반복 뽑기가 답답하지 않게 한다.
- `prefers-reduced-motion` 환경에서는 애니메이션 없이 즉시 결과를 표시한다.

### 3. 출생 프로필

- 상단: 출생 번호, 출생 연도(현재 연도인 2026년), 지역 코드
- 대표 정보: 시도와 세부 지역
- 조건 카드:
  - 부모 구성
  - 보호자 1·2의 직업 또는 부재 상태
  - 가정 형편
  - 주거 형태
  - 형제자매 수
- 초기 능력치:
  - 건강
  - 안정
  - 교육 기회
  - 관계
- 능력치는 조건에 따른 시작 경향을 보여 주지만 미래를 결정하지 않는다는 문구를 함께 제공한다.
- 주요 동작: `이 인생 시작하기`
- 보조 동작: `다시 태어나기`, `이전 인생`

### 4. 다음 단계 예고

- 현재 프로필을 작은 요약 카드로 유지한다.
- 다음에 추가할 성장 선택을 미리 보여 준다: 고등학교 유형, 직업군, 세부 직업.
- MVP에서는 실제 성장 시뮬레이션을 시작하지 않고 `곧 이어집니다` 상태로 마무리한다.
- `다른 인생 뽑기`로 결과 화면에 돌아갈 수 있다.

## 랜덤 생성 모델

이번 버전은 실제 인구통계 API와 연결하지 않는다. 모든 확률은 체험용 가중치이며, 코드에서 데이터와 로직을 분리해 나중에 공식 통계로 교체할 수 있게 한다.

### 지역

- 대한민국 17개 시도 전체를 포함한다.
- 각 시도는 3~6개의 대표 세부 지역 후보를 가진다.
- 수도권은 조금 더 자주 등장하도록 가중치를 주되 실제 인구 비율이라고 표현하지 않는다.

### 가족과 환경

- 부모 구성: 양부모, 한부모, 조부모 동거, 보호자 가정 등
- 부모 직업: 사무·관리, 전문직, 서비스·판매, 생산·기술, 운송, 농림어업, 공공·교육, 자영업, 구직·휴직 등
- 가정 형편: 빠듯함, 보통, 여유 있음
- 주거 형태: 자가, 전세, 월세, 공공임대, 가족 소유 주택
- 조건 조합은 부자연스러운 충돌이 없도록 후처리 규칙을 둔다.

### 초기 능력치

- 각 조건이 능력치에 작은 가감치를 주고 마지막에 제한 범위로 보정한다.
- 같은 조건이라도 소량의 무작위성을 더해 완전히 동일한 인생이 반복되지 않게 한다.
- 특정 지역, 가족 형태, 직업을 실패나 열등함과 직접 연결하지 않는다.

## 상태와 기록

- 현재 프로필과 직전 프로필을 브라우저 메모리에서 관리한다.
- 직전 결과가 있을 때만 `이전 인생` 버튼을 활성화한다.
- 새로고침 후에도 마지막 결과를 유지하도록 `localStorage`에 저장한다.
- 개인정보 입력이나 서버 전송은 없다.

## 비주얼 시스템

### 색상

사용자가 제공한 팔레트를 CSS 변수로 고정한다.

| 용도 | 라이트 | 다크 |
|---|---|---|
| 가장 밝은 바탕·본문 | `#F3F5F1` | `#EEF3EC` |
| 보조 바탕 | `#E1E6DD` | `#1A211C` |
| 경계·중간 톤 | `#C8D0C2` | `#26302A` |
| 깊은 녹색 바탕 | `#16201A` | `#111613` |
| 주요 포인트 | `#22C55E` | `#3DF08A` |

이번 MVP는 다크 모드를 기본으로 하고 제공된 팔레트 밖의 강조색은 추가하지 않는다. 주요 확정 동작은 밝은 초록색으로 강조한다. 카드 배경은 `#1A211C`, 내부 구획은 `#26302A`, 페이지 배경은 `#111613`을 사용한다.

### 타이포그래피

원작 사이트에서 확인한 조합을 따른다.

- 디스플레이·큰 제목: `Hahmlet`, 500
- 본문·버튼: `IBM Plex Sans KR`, 400·600
- 번호·코드·능력치: `IBM Plex Mono`, 400·600
- 폰트 파일은 외부 원작 서버에 의존하지 않고 공식 배포 또는 허용된 웹 폰트 소스를 사용한다.

### 형태와 모션

- 큰 라운드 카드보다 각진 패널과 얇은 테두리를 중심으로 구성한다.
- 카드에 과도한 그림자를 쓰지 않는다.
- 셔플 중에는 텍스트, 좌표, 얇은 스캔 라인이 움직이고 결과 확정 시 초록색 점이 켜진다.
- 버튼은 키보드 포커스가 명확해야 하며 터치 영역은 최소 44px로 한다.

## 반응형 동작

- 모바일에서는 한 열 구조와 하단 고정 액션 바를 사용한다.
- 데스크톱에서는 좌측에 출생 정보, 우측에 가족 조건과 능력치를 배치한다.
- 360px 너비에서도 가로 스크롤 없이 모든 항목을 볼 수 있어야 한다.
- 큰 화면의 콘텐츠 최대 너비는 약 1180px로 제한한다.

## 접근성과 문구 원칙

- 색상만으로 상태를 구분하지 않는다.
- 모든 버튼에 명확한 한글 레이블을 제공한다.
- 결과 변경은 스크린리더에 알려 준다.
- 가정 형편이나 가족 구성을 평가하거나 낙인찍는 표현을 피한다.
- 다음 문구를 인트로와 결과 화면에 반복해서 표시한다: `현재 결과는 실제 인구통계가 아닌 체험용 가상 시뮬레이션입니다.`

## 구현 구조

첫 MVP는 빠른 로딩과 배포를 위해 빌드 없는 정적 HTML, CSS, JavaScript로 구현한다.

- `dist/index.html`: 화면 구조와 접근 가능한 문구
- `dist/styles.css`: 디자인 토큰, 반응형 레이아웃, 모션
- `dist/data.js`: 지역·가족·직업 후보와 체험용 가중치
- `dist/app.js`: 생성 로직, 상태 전환, 기록, 렌더링
- `.openai/hosting.json`: Sites 정적 배포 설정

데이터와 화면 로직을 나누어 이후 성장 타임라인을 추가할 때 기존 출생 생성기를 그대로 재사용한다.

## 검증 기준

- 17개 시도가 모두 생성 후보에 포함된다.
- `다시 태어나기`가 매번 새 프로필을 생성한다.
- `이전 인생`이 바로 전 결과를 정확히 복원한다.
- 새로고침 후 마지막 결과가 유지된다.
- 생성 중 중복 입력을 막고 1.2초 안에 결과를 표시한다.
- 모바일과 데스크톱 레이아웃이 깨지지 않는다.
- 키보드만으로 모든 동작을 수행할 수 있다.
- 실제 통계가 아니라는 안내가 인트로와 결과 모두에서 보인다.

## 이번 범위에서 제외

- 실제 통계 API 연동
- 회원가입과 서버 저장
- 전체 생애 타임라인
- 고등학교·직업의 실제 선택과 결과 계산
- 공유 이미지 생성
- 결제, 광고, 커뮤니티 기능
