# 시대·역사·룰렛 확장 설계

## 목적

`5000만 분의 1`을 단일한 현재 대한민국 배경의 선택형 시뮬레이션에서, 1950년대부터 미래까지 출생 시점에 따라 사회 환경과 개인의 생애가 달라지는 한국형 시대 인생 시뮬레이션으로 확장한다.

완료 기준은 다음과 같다.

- 사용자가 1950년대부터 현재까지 10년 단위로 출생 시대를 고를 수 있다.
- 역사적 사건은 실제 발생 연도에만 나타나고, 개인에게 미치는 결과만 조건에 따라 달라진다.
- 미래 사건은 역사적 사실과 혼동되지 않도록 전망 시나리오로 표시된다.
- 제공된 `slot-machine (1).html`의 시각 구조와 순차 정지 경험이 출생 설정 화면에 반영된다.
- 시작 화면에 대한민국 전도와 17개 시도 위치가 표시된다.
- 공개된 삶과 추모관에는 샘플 기록이 나타나지 않는다.
- 병역 면제 여부는 사용자가 선택할 수 없고 자동 판정된다.
- 미성년자의 개인 현금과 가정의 경제적 지원이 분리된다.
- 인생 진행 상황은 성장하는 캐릭터와 연령 경로로 시각화된다.

## 사용자 경험

### 시작 화면과 시대 선택

시대 선택지는 다음과 같이 고정한다.

- 완전 무작위
- 1950년대
- 1960년대
- 1970년대
- 1980년대
- 1990년대
- 2000년대
- 2010년대
- 2020년대
- 미래 대한민국

연대를 고르면 해당 10년 안에서 출생연도가 결정적으로 추첨된다. `2020년대`는 현재 연도인 2026년을 넘지 않으며, 미래는 현재 연도 이후 35년 안에서 추첨한다. 완전 무작위는 모든 과거 연대·현재·미래를 포함하되 현재와 가까운 시대가 조금 더 자주 나오도록 한다.

시작 화면 오른쪽의 추상 레이더는 대한민국 전도 기반 SVG로 교체한다. 지도에는 17개 시도의 위치 점을 표시하고, 출생 전에는 순차 점멸하며, 출생지가 정해진 뒤에는 해당 시도만 강조한다. 지도는 장식용이지만 시도 이름을 별도 접근성 텍스트로 제공한다.

### 출생 룰렛

사용자가 제공한 `/Users/chaeho/Downloads/slot-machine (1).html`을 시각 기준으로 삼는다. 독립 HTML을 그대로 삽입하지 않고 현재 데이터 엔진과 접근성 구조에 맞게 다음 요소를 재구성한다.

- 상단 5개 릴: 성별, 출생지, 가정환경, 장애, 외모
- 하단 왼쪽 3개 릴: 성격 세 번 추첨
- 하단 오른쪽 3개 릴: 성과 이름 두 글자
- 중앙 진행 표시등
- 하단 원형 `태어나기` 버튼
- 상단 릴이 먼저 멈춘 후 성격과 이름이 순차적으로 멈추는 애니메이션

결과 데이터는 기존 `createBirthSlotResult`가 유일한 출처가 된다. 제공 HTML의 하드코딩 데이터나 2026년 전용 지역 통계는 복사하지 않는다. 모션 감소 환경에서는 애니메이션 없이 즉시 결과를 보여준다. 결과가 마음에 들지 않으면 같은 화면에서 계속 재추첨할 수 있다.

### 비교 인생과 공개 기록

`함께 태어난 네 사람` 기능과 관련 UI, 생성·진행 로직을 제거한다. 실제 사용자가 아닌 가상 인물을 실제 비교 대상처럼 보여주는 혼란을 없앤다.

공개된 삶과 추모관은 `community-samples.js`의 샘플을 사용하지 않는다.

- 공개된 삶: 사용자가 실제로 완료 후 공개한 최소 정보 기록만 표시
- 추모관: 공개 기록 가운데 생애가 90세 이전에 끝난 기록만 표시
- 기록이 없으면 설명과 함께 빈 상태 표시
- Supabase가 연결되지 않은 환경에서는 현재 브라우저에서 공개한 기록만 표시
- 서버 연결이 없는데 온라인 기록이 있는 것처럼 보이는 숫자도 제거하거나 로컬 상태로 표시

### 미성년자의 경제

개인 현금과 가정 지원을 분리한다.

- 출생 시 `economy.cash`는 0원이다.
- `economy.householdSupport`에 가정형편 기반 지원 여력을 저장한다.
- 18세 미만 화면에서 개인 현금은 숫자 대신 `—`로 표시한다.
- 사교육처럼 미성년기 가정이 부담하는 비용은 개인 현금이 아니라 가정 지원에서 차감한다.
- 아르바이트·장학금·취업 등 개인에게 귀속되는 수입은 개인 현금에 들어간다.
- 기존 저장본은 현재 현금을 가정 지원으로 안전하게 이전하지 않는다. 저장본의 진행 상태를 보존하고, 새로 생성되는 삶부터 새 모델을 적용한다.

### 병역 판정

병역은 선택 전에 시스템이 판정한다. 판정 결과는 생애 상태의 `service`에 저장한다.

- 비대상: 병역 의무 대상이 아닌 프로필
- 현역
- 보충역
- 전시근로역
- 병역면제
- 재검사

판정은 프로필의 성별, 장애 지원 필요도, 당시 건강 상태, 출생연도와 결정적 난수를 조합한다. 실제 개인의 법률적·의학적 판정을 재현한다고 주장하지 않으며, 병무청의 신체등급별 처분 구조만 단순화해 사용한다.

사용자는 `면제`나 `비대상`을 선택할 수 없다. 시스템이 자동으로 판정하고 기록한다. 현역·보충역 판정자에게만 시작 시기 또는 허용된 진행 선택지를 제공한다. 재검사 판정은 다음 해에 자동 재판정한다. 기존의 길고 방어적인 안내 문구는 결정 본문에서 제거하고, 상세 정보 영역에 짧은 시뮬레이션 안내와 출처를 둔다.

### 역사적 사건

역사 사건은 `startYear`, `endYear`, `ageRange`, `region`, `occupation`, `effects`, `source`를 가진 데이터 항목으로 관리한다. 한 사건은 같은 삶에서 한 번만 발생하며, 생애의 실제 달력 연도가 범위에 들어올 때만 후보가 된다.

초기 사건 범위는 다음과 같다.

- 1950~1953: 한국전쟁, 피란과 가족 분리, 학교 중단
- 1954~1960: 전후 복구, 원조 물자, 의무교육 확대
- 1962~1969: 경제개발계획, 공업단지, 농촌에서 도시로의 이동
- 1970~1979: 새마을운동, 중화학공업, 대규모 이촌향도
- 1980~1989: 산업도시 성장, 민주화운동, 1988 서울올림픽
- 1990~1996: 대중문화·PC통신·소비사회 확대
- 1997~2001: 외환위기, 실업과 가계 재편
- 2002~2009: 월드컵, 초고속 인터넷, 세계 금융위기
- 2010~2019: 스마트폰 일상화, 플랫폼 노동, 주거비 압박
- 2020~현재: 감염병, 원격수업·재택근무, 금리와 생활비 변화

사건 제목과 발생 연도는 고정된 사실로 유지한다. 건강·행복·자산·관계 변화는 게임상의 가상 결과이며, 지역·나이·직업·가정형편에 따라 다르게 적용한다. 정치적 사건은 특정 선택을 정답으로 강요하지 않고 개인이 겪는 생활 변화 중심으로 서술한다.

### 미래 전망 사건

현재 연도 이후의 사건은 `projection: true`로 구분하고 UI에 `전망 시나리오` 배지를 표시한다. 초기 범위는 다음과 같다.

- AI 동료와 업무 자동화
- 직무 재교육과 자격 전환
- 자동화된 교통·배송의 보편화
- 합성 미디어를 이용한 사기와 신원 확인
- 돌봄 로봇과 원격 건강관리
- 폭염·극한강수에 따른 주거 및 노동 변화
- 고령화와 1인 가구 증가에 따른 지역 서비스 재편

정부 정책 목표나 인구·기후 전망을 사건의 방향 근거로 사용하지만, 구체적 개인 결과는 창작 시뮬레이션으로 표시한다.

### 성장 캐릭터

현재 생애 화면에 `life-character` SVG를 추가한다. 캐릭터는 사실적인 인물 그림이 아니라 원작의 단순한 진행 아이콘에 가까운 형태로 만든다.

- 영유아, 아동, 청소년, 청년, 중년, 노년의 여섯 단계
- 현재 나이에 따라 체형과 자세가 바뀜
- 건강·행복 상태에 따라 자세와 주변 색이 달라짐
- 인생 지도에서 0~90세 진행률에 맞춰 위치가 이동함
- 장애·인종·성별을 우열이나 희화화로 표현하지 않음
- 모션 감소 환경에서는 위치 전환 애니메이션을 사용하지 않음

## 구조

### 새 데이터 모듈

- `dist/data/eras.js`: 시대 선택지, 연대별 출생연도 범위, 표시 문구
- `dist/data/history-events.js`: 실제 연도 기반 역사 사건
- `dist/data/future-events.js`: 전망 시나리오 사건

### 새 엔진 모듈

- `dist/engine/era-events.js`: 현재 달력 연도에 맞는 역사·미래 사건 선택과 중복 방지
- `dist/engine/service.js`: 병역 대상 여부와 처분 결과 자동 판정

### 수정 모듈

- `dist/data/runtime-settings.js`: 10년 단위 시대 설정
- `dist/engine/birth-slot.js`: 시대 결과 보존과 새 룰렛 뷰 모델 지원
- `dist/engine/life.js`: 가정 지원, 병역 상태, 시대 사건 기록 필드 정규화
- `dist/engine/decisions.js`: 미성년 비용의 가정 지원 차감
- `dist/engine/events.js`: 연간 사건과 시대 사건의 순서 통합
- `dist/ui/birth-slot.js`: 제공 룰렛 구조 렌더링
- `dist/ui/render.js`: 경제 표시, 성장 캐릭터, 전망 배지, 빈 공개 기록 렌더링
- `dist/app.js`: 비교 인생 제거, 지도 강조, 새 룰렛 상호작용
- `dist/community.js`: 샘플 기본값 제거와 추모 기록 필터
- `dist/index.html`, `dist/styles.css`: 지도, 룰렛, 캐릭터 및 빈 상태 UI

## 데이터 흐름

1. 사용자가 시대를 고른다.
2. 설정과 seed로 출생연도를 결정한다.
3. 출생 룰렛이 한 번의 `createBirthSlotResult` 결과를 순차적으로 공개한다.
4. `createLife`가 출생연도, 가정 지원, 병역 미판정 상태를 저장한다.
5. 매년 진행 시 달력 연도를 먼저 갱신한다.
6. 해당 연도의 미발생 역사 사건 또는 미래 전망 사건을 평가한다.
7. 병역판정 나이가 되면 시스템 판정을 먼저 수행하고, 필요한 경우에만 결정 화면을 연다.
8. UI는 현재 나이와 상태로 캐릭터·지도·경제·사건 출처를 갱신한다.

## 오류와 호환성

- 기존 버전 2~4 저장본을 계속 불러온다.
- 새 필드가 없는 저장본은 현재 시대, 가정 지원 없음, 병역 미판정 상태로 보완한다.
- 시대 사건 데이터가 없거나 잘못돼도 일반 연간 사건은 계속 진행한다.
- Supabase 연결 실패 시 공개 기록 화면은 샘플 대신 빈 상태 또는 로컬 기록을 보여준다.
- 제공 룰렛의 외부 CDN 폰트는 새 의존성으로 추가하지 않고 기존 사이트 글꼴을 유지한다.
- 미래 전망은 현재 연도 이전 삶에 나타나지 않으며, 역사 사건은 미래 출생 삶에 과거 회상처럼 삽입되지 않는다.

## 검증

- 각 연대 설정이 올바른 출생연도 범위를 생성하는지 단위 테스트
- 1950~2020년대와 미래 사건이 올바른 달력 연도에서만 발생하는지 테스트
- 역사 사건의 중복 발생 방지 테스트
- 미래 사건의 전망 배지 및 역사 사건과의 분리 테스트
- 병역 면제·비대상 선택지가 사용자 선택으로 노출되지 않는지 테스트
- 같은 seed와 상태에서 같은 병역판정이 나오는지 테스트
- 0세 개인 현금 0원, 미성년 화면 `—`, 사교육비 가정 지원 차감 테스트
- 공개 기록 샘플이 없고 추모관 필터가 실제 조기 종료 기록만 남기는지 테스트
- 함께 태어난 네 사람 관련 UI와 런타임 필드가 제거되는지 테스트
- 제공 룰렛의 11개 릴, 순차 상태, 재추첨, 모션 감소 동작 테스트
- 성장 캐릭터가 여섯 연령 단계와 0~90세 진행률을 반영하는지 테스트
- 전체 100개 seed 완주 테스트와 기존 저장본 마이그레이션 테스트
- 데스크톱·모바일 브라우저에서 한 화면 구성, 키보드 조작, 콘솔 오류를 확인
