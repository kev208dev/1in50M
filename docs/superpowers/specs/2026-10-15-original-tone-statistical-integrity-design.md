# 원작 톤·통계 신뢰도 개선 설계

## 목적

「5000만 분의 1」을 선택 결과를 최적화하는 게임보다, 선택할 수 없었던 출생 조건과 시대가 한 사람의 삶에 어떻게 누적되는지 체험하는 작품으로 다듬는다. 기존 Figma 화면 구조와 한국형 강점은 유지하되, 비교 분석 보고서에서 확인된 정체성 충돌, 시대 고증 오류, 능력치 포화, 후반부 공백을 함께 해결한다.

성공 기준은 다음과 같다.

- 한 번 정해진 출생은 해당 생애에서 다시 뽑을 수 없다.
- 선택 전에는 정확한 능력치 증감을 보여주지 않는다.
- 지명, 교육 제도, 역사 사건이 생애 연도와 나이에 맞는다.
- 사건과 선택 결과가 연도순으로 하단 시스템 기록에 누적된다.
- 출생 조건, 시대, 선택이 같은 결정을 서로 다른 결과로 만든다.
- 고령기까지 의미 있는 사건과 결정이 이어지고, 사망 원인과 건강 상태가 모순되지 않는다.
- 데스크톱과 모바일 모두 페이지 스크롤 없이 핵심 조작이 가능하다.

## 범위

### 포함

- 출생 추첨과 인트로 문구의 비가역성 강화
- 한국식 출생신고 카드
- 시대별 지명 및 제도 유효 기간
- 공식 공개 통계를 바탕으로 한 버전 고정 데이터 계층
- 선택지 결과 수치 비공개와 사후 기록
- 사건 큐의 연도순 보장 및 구체적인 장면 서술
- 나이·지역·가정 형편에 따른 역사 사건 변형
- 같은 해 태어난 비교 인물 네 명
- 능력치 체감 효과와 연령별 변화
- 50세 이후 사건·결정 보강
- 사망 시점·사망 원인·엔딩 개선
- 모바일 입력과 자동 재생 흐름 개선
- 자동 테스트 및 브라우저 검증

### 제외

- 실시간 KOSIS API 연동
- 주민등록번호를 닮은 식별 정보 생성
- 금융 수익을 실제 투자 예측처럼 제공하는 기능
- 모든 시군구·모든 연도의 완전한 원자료 수록
- 기존 공개 생애 데이터의 파괴적 마이그레이션

## 설계 원칙

1. **비가역성**: 출생 결과는 한 생애에 한 번만 정한다.
2. **사후 이해**: 선택 전에는 효과 방향만 암시하고, 실제 변화는 결과 기록에서 설명한다.
3. **연도 우선**: 선택지와 사건은 현재 나이보다 생애의 실제 연도를 먼저 검증한다.
4. **출처 추적 가능성**: 통계 값마다 기관, 기준 연도, URL 또는 문헌 식별자를 연결한다.
5. **한국형 구체성**: 전국 평균보다 시도·시군구, 가족 구성, 통학, 고용과 주거 상황을 우선 사용한다.
6. **정적인 재현성**: 같은 시드와 설정은 같은 출생·사건·사망 결과를 만든다.

## 아키텍처

### 1. 시대·통계 데이터 계층

새로운 데이터 모듈은 다음 정보를 한곳에서 제공한다.

- 행정구역의 시대별 표기 규칙
- 교육·복지·고용 제도의 시작·종료 연도
- 출생지 가중치, 기대수명, 사망 원인, 소득 분위 등 공개 통계 스냅샷
- 각 값의 출처 메타데이터

외부 API를 플레이 중에 호출하지 않는다. 저장소에 검증한 최소 데이터만 버전 고정하여 배포하고, 값이 없는 연도는 가장 가까운 과거 스냅샷을 사용하면서 화면에 기준 연도를 표시한다. `availableFrom`, `availableUntil`, `regionAliases` 같은 공통 필드를 사용해 선택지와 지명에 동일한 검증 규칙을 적용한다.

### 2. 출생 흐름

기존 Figma 프레임의 지도와 추첨 연출은 유지한다. 다만 다음과 같이 바꾼다.

1. 인트로를 터치·클릭 가능한 중립적 시작 화면으로 만든다.
2. 출생 추첨은 한 번만 실행한다.
3. 릴은 순차적으로 멈추고, 멈춘 뒤 재추첨 버튼을 표시하지 않는다.
4. 바로 대시보드로 가지 않고 출생신고 카드를 표시한다.
5. 카드는 출생 문장, 당시 지명, 가족 상황, 기대수명과 기준 연도, 비교 인물 요약을 담는다.
6. 사용자가 생애 시작을 누르면 후보 프로필을 확정한다.

엔딩에서는 `같은 조건으로 다시`를 제거한다. 새 생애는 새로운 출생으로만 시작할 수 있다.

### 3. 동시대 비교 인물

주인공과 같은 출생 연도에 다른 시도와 경제 조건에서 태어난 네 명의 경량 프로필을 시드로 생성한다. 비교 인물은 전체 생애 엔진을 네 번 돌리지 않고, 연령대별 상태 요약을 계산하는 전용 모델을 사용한다.

- 출생, 학령기, 청년기, 중년기, 노년기 단계에서만 갱신한다.
- 생존 상태, 거주 지역, 교육·직업 범주, 경제 구간을 보여준다.
- 주인공의 선택을 복제하지 않는다.
- 비교는 순위가 아니라 서로 다른 출발 조건과 경로를 보여주는 용도다.

### 4. 선택과 능력치

선택지 카드에서 `지식 +5`, `행복 -1` 같은 정확한 숫자를 제거한다. 대신 `배움에 도움`, `회복 시간 감소`처럼 방향과 성격만 표시한다. 접근 불가능한 선택지는 잠금 이유만 설명한다.

효과 계산은 다음 순서로 처리한다.

1. 선택의 기본 효과
2. 출생 가정·지역·교육 접근성 보정
3. 현재 능력치가 상한에 가까울수록 증가 폭이 줄어드는 체감 효과
4. 연령대별 건강·관계·지식의 자연 변화
5. 성격에 따른 선택 거부 또는 수정

실제 적용된 변화는 하단 시스템 기록에 자연어로 남긴다. 숨긴 숫자를 다른 팝업에서 즉시 다시 노출하지 않는다. 결과 화면의 최종 통계와 분석에는 숫자를 유지한다.

금융·투자 기능은 삭제하지 않는다. 성인기 전에는 숨기고, 성인기에는 별도 메뉴에서만 접근하게 한다. 도파민은 내부 위험 변수로 유지하되 기본 상단 HUD에서는 제거하고, 가상자산 결과 메시지와 위험 경고에서만 표현한다.

### 5. 사건 큐와 역사 사건

모든 자동 사건, 역사 사건, 회고, 결정, 대형 카드를 `{ year, age, priority, sequence }` 기준으로 하나의 큐에서 정렬한다. 같은 틱에 여러 항목이 생겨도 연도가 역행하지 않는다.

사건 생성 규칙은 다음과 같다.

- 아무 변화가 없는 해의 범용 문장은 기록하지 않는다.
- 역사 사건은 당시 나이, 지역, 보호자 직업, 가정 형편으로 장면을 선택한다.
- 사건 본문은 한 장면을 서술하고, 필요한 경우 짧은 통계 설명을 덧붙인다.
- 출처는 작지만 읽을 수 있는 대비로 표시하며, 출처 상세 창에서 기관·기준 연도·링크를 확인할 수 있다.
- 자동 질병과 사회적 사건도 선택 결과와 같은 시스템 기록에 연속해서 나타난다.

### 6. 교육·상태 고증

교육 상태는 나이에 따라 최소한 다음 단계로 자동 갱신한다.

- 0~1세: 영아
- 2~6세: 유아·미취학
- 7~12세: 초등학교
- 13~15세: 중학교
- 16세 이후: 선택한 고등학교 또는 다른 경로

교육 선택지는 실제 연도로 제한한다. 예를 들어 초등돌봄교실은 2004년 이후, 마이스터고와 자율형 사립고는 해당 제도가 존재하는 연도부터 나타난다. 비용 표시와 잠금 판정은 동일한 값을 사용한다.

행정구역은 출생 연도를 기준으로 표시한다. 예를 들어 화성은 2001년 이전 출생 카드와 과거 사건에서 `화성군`으로 표시하고, 이후 현재 상태에서는 필요할 때 `현 화성시`를 병기할 수 있다.

### 7. 후반 생애와 사망

50세 이후에 건강검진, 만성질환, 부모·배우자 돌봄, 퇴직, 재취업, 관계 변화, 사별, 주거 축소, 지역 이동 사건을 배치한다. 결정 간 공백이 지나치게 길지 않도록 연령대별 최소 사건 밀도를 둔다.

사망 엔진은 성별·연령별 생명표 스냅샷을 기본 위험으로 사용하고, 건강과 위험 요인으로 보정한다. 사망 원인은 성별·연령대별 원인 분포에서 고르되, 현재 건강 및 누적 질병과 모순되는 원인은 제외하거나 설명 가능한 선행 사건을 요구한다.

### 8. 엔딩

엔딩은 다음 순서로 구성한다.

1. 생애 요약과 사망 원인
2. 가장 큰 행복 변화 또는 장기 영향이 있었던 대표 사건
3. 출생 조건의 영향
4. 같은 해 태어난 네 명의 현재 또는 생애 요약
5. `이 사람에게 한마디` 입력
6. 추모관 이동
7. 익명 공개와 새 생애 시작

대표 사건은 단순히 마지막 사건이나 균등 간격 표본을 고르지 않고, 능력치 변화량·지속 기간·관계 변화에 점수를 매겨 선택한다.

### 9. 재생과 모바일

- 키보드 전용 문구를 `화면을 눌러 시작`으로 바꾸고 키보드도 계속 지원한다.
- 결정 창이 열리기 전 재생 중이었다면 결정 후 자동으로 재생한다.
- 사용자가 직접 일시정지한 상태는 유지한다.
- 페이지 자체 스크롤은 계속 잠그고, 긴 내용은 모달 또는 패널 내부에서만 스크롤한다.
- 작은 화면에서는 상단 상태를 축약하고 시스템 기록과 현재 결정이 가려지지 않게 한다.

## 데이터와 호환성

기존 저장 데이터는 정규화 단계에서 새 필드의 기본값을 채운다. 과거 생애 요약과 공개 생애는 계속 읽을 수 있어야 한다. 새 데이터 버전은 생애에 기록하여 이후 통계 스냅샷이 바뀌어도 저장된 생애를 동일하게 재현한다.

출처가 없는 기존 창작 수치는 공개 통계처럼 표시하지 않는다. 통계 기반 값, 모델링 값, 순수 서사 값의 종류를 내부적으로 구분한다.

## 오류 처리

- 특정 연도의 데이터가 없으면 가장 가까운 과거 자료와 기준 연도를 사용한다.
- 유효한 과거 자료가 없으면 전국 기본값을 사용하고 `모델링 값`으로 표시한다.
- 시대 조건에 맞지 않는 저장된 선택지는 안전한 일반 경로로 정규화한다.
- 비교 인물 생성 실패는 주인공 생애 진행을 막지 않고 비교 영역만 숨긴다.
- 외부 출처 링크 오류는 게임 진행에 영향을 주지 않는다.

## 테스트 전략

### 자동 테스트

- 출생 추첨은 한 번만 가능하며 재추첨 UI가 없다.
- 엔딩에 동일 조건 재시작이 없다.
- 1985년 화성 출생은 화성군으로 표시된다.
- 돌봄교실, 마이스터고, 자사고가 제도 시작 전에는 나타나지 않는다.
- 교육 상태가 나이에 맞게 갱신된다.
- 사건 큐가 연도와 나이 순서를 지킨다.
- 선택 전 정확한 능력치 수치가 노출되지 않는다.
- 상한 근처 능력치 증가량이 낮은 능력치보다 작다.
- 금융 메뉴는 성인기 전에는 숨겨진다.
- 사망 원인과 건강·질병 상태가 일관된다.
- 50세 이후에도 사건과 결정이 생성된다.
- 비교 인물 네 명이 같은 시드에서 재현된다.
- 대표 사건이 가장 큰 영향을 기준으로 선택된다.
- 기존 저장 데이터가 새 모델로 정규화된다.

### 브라우저 검증

- 1440×1024, 1366×768, 390×844, 360×800에서 페이지 스크롤과 잘림을 확인한다.
- 출생부터 엔딩까지 최소 세 번 플레이한다: 1980년대, 현재, 무작위 시대.
- 제도 경계 연도 전후와 행정구역 변경 전후를 확인한다.
- 자동 재생, 수동 일시정지, 결정 후 재개를 확인한다.
- 비교 인물, 시스템 기록, 출처 상세, 추모 메시지를 키보드와 터치로 확인한다.
- 콘솔 오류와 접근성 이름 누락을 확인한다.

## 배포

전체 자동 테스트와 실제 브라우저 검증이 통과한 뒤 `main`에 반영한다. GitHub Pages 배포 완료 후 라이브 사이트에서 데스크톱과 모바일 핵심 흐름을 다시 확인한다.
