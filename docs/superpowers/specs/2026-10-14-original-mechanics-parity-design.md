# 5000만 분의 1 — 원작형 전체 메커니즘 재구성 설계

## 목표

현재 대한민국형 생애 시뮬레이션에 `1in8b.life`의 전체 플레이 리듬을 기능적으로 재구성한다. 원작의 코드, 문구, 이미지, 음원을 복제하지 않고, 출생 전 설정부터 무작위 출생, 자동으로 흐르는 생애, 조건부 선택, 회고, 사망, 다른 삶과의 비교, 공개 삶과 추모관까지 동일한 종류의 경험을 대한민국의 제도와 생활 맥락으로 새로 만든다.

## 확정된 범위

- 시작 화면의 실시간 접속자·가상 출생·가상 사망 카운터와 최근 공개 삶
- 시대, 생애 진행 시간, 대한민국 기준 비교, 음악, 자동 선택 설정
- 무작위 출생 슬롯과 상세 출생증명서
- 같은 순간 태어난 네 명의 비교 인생
- 0세부터 사망까지 자동 시간 진행
- 일시정지, `1×`, `2×`, `4×`, `8×`, `12×`, `16×`, 다음 선택까지 진행
- 중요한 결정에서 일시정지하고 답변 후 선택 전의 재생 상태와 배속으로 자동 복귀
- 성격 개입 안내가 있는 경우 안내를 닫은 뒤 자동 복귀
- 연간 초점, 연간 사건, 교육, 진로, 직업, 주거, 관계, 건강, 외모, 자산, 투자, 도박, 창업
- 생존 곡선, 자산·상태 변화, 가족, 인생 지도, 자료 출처
- 5세, 15세, 30세, 50세, 70세의 회고
- 생애 종료 요약, 공개, 공유, 다시 태어나기, 전생 기록
- 익명 실시간 참여, 공개 삶, 추모관
- 데스크톱과 모바일에서 핵심 조작과 현재 상태가 한 화면에 보이는 반응형 UI

## 저작권 및 데이터 원칙

- 원작의 소스 코드, 에셋, 장문 카피, 고유 그래픽을 복사하지 않는다.
- 기능 구조와 상호작용 패턴을 대한민국형 콘텐츠와 기존 색상 팔레트로 독자 구현한다.
- 실제 통계가 연결되지 않은 수치에는 `체험용 가상 시뮬레이션`을 항상 표시한다.
- 금융, 도박, 건강, 성 정체성 결과는 조언·진단·개인 판정으로 표현하지 않는다.
- 공개 저장 데이터에는 실명, 연락처, 정확한 주소 등 개인 정보를 받지 않는다.

## 플레이 흐름

1. 방문자는 현재 온라인 인원, 가상 출생·사망 흐름, 최근 공개된 삶을 본다.
2. 시대와 생애 진행 시간, 비교 기준, 음악, 자동 선택을 정한다.
3. `태어나기`를 누르면 출생 슬롯이 돌고 출생 조건이 정해진다.
4. 출생증명서는 이름, 시도·세부 거주지, 도시성, 가족 형편, 부모 구성·직업, 종교, 외모, 성격, 기대수명을 보여 준다.
5. 마음에 들지 않으면 무제한으로 다시 뽑고, 수락하면 네 명의 비교 인생과 함께 삶을 시작한다.
6. 시간은 선택 전까지 자동으로 흐른다. 선택을 완료하면 자동으로 계속 흐른다.
7. 해마다 조건에 맞는 0~2개의 사건이 일어나며 상태·돈·관계·거주·진로가 누적된다.
8. 생존 확률이 매년 평가되어 90세 이전에도 삶이 끝날 수 있다.
9. 생애 종료 후 삶을 브라우저에 보관하고, 사용자가 원하면 익명 공개 기록으로 게시한다.
10. 공개 기록은 최근 삶과 추모관에서 읽을 수 있으며 작성자는 자신의 기록만 숨길 수 있다.

## 진행 엔진

- 모든 삶은 재현 가능한 `seed`를 가진다.
- 기본 단위는 1년이며 생애 진행 시간 설정으로 실제 틱 간격을 계산한다.
- 재생 중 선택이 열리면 `resumeAfterInterruption`에 기존 재생 상태를 저장한다.
- 일반 선택은 적용과 동시에 재생을 복구한다.
- 성격 개입, 정체성 발견, 회고처럼 후속 모달이 있으면 후속 모달 확인 뒤 재생을 복구한다.
- 사용자가 선택 전에 직접 일시정지했다면 답변 뒤에도 정지 상태를 유지한다.
- 탭이 숨겨진 동안 시간은 흐르지 않고 복귀 후 누적 시간을 한꺼번에 처리하지 않는다.

## 생존과 회고

- 생존 확률은 나이, 건강, 사건, 생활 습관으로 계산한다.
- 학원·야간 자율학습·밤샘 선택은 학업 스트레스, 수면 부채, 고카페인 부담을 누적한다.
- 스트레스와 수면 부족이 함께 오래 누적되면 우울·불안 위기와 건강 저하가 발생할 수 있고, 위기가 극심한 경우 자해·자살로 인한 조기 사망도 희귀하게 발생할 수 있다.
- 고카페인 섭취와 수면 부족이 극심하게 겹치면 심혈관 건강 위기로 조기 사망할 수 있다.
- 정신건강 위기와 카페인 관련 결과는 비묘사적으로 표현하고, 단일 선택이 결과를 확정하지 않도록 여러 누적 요인을 함께 평가한다.
- 휴식, 일정 축소, 신뢰하는 어른·전문가에게 도움 요청 같은 선택은 위험을 크게 낮추며, 이 도움 선택에는 성격 강제 개입을 적용하지 않는다.
- 사망 여부는 seed와 나이를 사용해 재현 가능하게 결정한다.
- 영유아, 청년, 중년, 노년의 위험 곡선이 서로 다르다.
- 폭력적 묘사는 사용하지 않는다.
- 회고는 정답이 없는 선택이며 행복·관계·초점과 이후 서술에 작은 영향을 준다.

## 비교 인생

- 네 명의 비교 인생은 같은 출생 연도와 시각을 공유하지만 지역·가정·성격·외모와 사건 seed가 다르다.
- 비교 인생은 사용자가 선택하지 않아도 자동 선택으로 독립 진행한다.
- 현재 나이, 거주지, 직업, 관계, 생존 여부를 요약해 보여 준다.
- 실제 다른 사용자의 개인 기록이 아니라 로컬 생성 가상 인생임을 표시한다.

## 온라인 계층

- Supabase Realtime Presence로 현재 접속자 수를 표시한다.
- 익명 인증 사용자에게 임의 별명과 소유자 ID를 부여한다.
- 공개 생애 테이블에는 요약, 출생 지역 단위, 사망 나이, 대표 직업, 순자산 구간, 회고 문장만 저장한다.
- 원본 생애 전체 상태와 민감한 프로필은 서버에 저장하지 않는다.
- 모든 공개 테이블에 RLS를 활성화한다.
- 누구나 공개 기록을 읽을 수 있고, 로그인된 익명 작성자만 자신의 기록을 생성·숨김 처리할 수 있다.
- 온라인 연결이 없거나 환경 설정이 없으면 로컬 카운터와 로컬 공개 샘플로 완전한 플레이가 가능해야 한다.

## 화면 구조

- 시작: 라이브 카운터, 최근 공개 삶, 설정, 태어나기 버튼을 한 화면에 배치한다.
- 출생: 슬롯 결과와 출생증명서, 비교 인생 네 명, 재추첨·수락 버튼을 한 화면에 배치한다.
- 생애: 상단 시간 조작, 왼쪽 프로필·상태·경제, 중앙 현재 장면·기록, 오른쪽 가족·비교 인생·생존 곡선을 한 화면에 배치한다.
- 좁은 화면에서는 상단 시간 조작과 현재 장면을 고정하고 나머지는 가로 전환 탭으로 접근한다.
- 기존 팔레트 `#111613`, `#1A211C`, `#26302A`, `#EEF3EC`, `#3DF08A`를 유지한다.
- 기존 폰트 구성을 유지한다.

## 완료 기준

- 선택 후 별도 재생 버튼을 누르지 않아도 시간이 계속 흐른다.
- 성격 개입 안내 중에는 흐르지 않고 안내 확인 후 계속 흐른다.
- 12배속을 포함한 모든 배속과 다음 선택 이동이 동작한다.
- 조기 사망을 포함해 여러 연령의 생애 종료가 가능하다.
- 같은 seed와 선택은 같은 결과를 만든다.
- 네 비교 인생이 사용자 삶과 함께 갱신된다.
- 온라인 연결 여부와 무관하게 생애를 완주할 수 있다.
- 연결된 환경에서는 실제 접속자와 공개 삶이 여러 브라우저에서 동기화된다.
- 360×800, 768×1024, 1440×900에서 핵심 조작과 현재 상태가 첫 화면에 보인다.
- 전체 자동화 테스트와 브라우저 수동 검증을 통과한다.
